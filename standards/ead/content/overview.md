**Encoded Archival Description (EAD)** is the international standard for encoding archival
finding aids in XML. It lets archives describe collections — their arrangement, content, and
context — in a consistent, machine-readable form that can be shared, searched, and preserved.

EAD 4 is part of the Encoded Archival Standards suite alongside [EAC-CPF](/eac) (record
creators) and [EAF](/eaf) (functions).

## Using the schema

Always track the latest EAD v4 release:

```
https://standards.openpreservation.org/ead/v4/ead.xsd
```

Or pin an exact version:

```
https://standards.openpreservation.org/ead/v4.0.0/ead.xsd
```

The XML namespace for EAD v4 is `https://standards.openpreservation.org/ead/v4`, and remains
stable across minor and patch releases.

## Governance

EAD is maintained by the Technical Subcommittee on Encoded Archival Standards (TS-EAS) of the
Society of American Archivists, in partnership with the Library of Congress.
