**Encoded Archival Functions (EAF)** provides a way to describe the *functions* — the
activities, processes, and responsibilities — of the corporate bodies, persons, and families
that create and use archival records. It complements [EAD](/ead) (describing records) and
[EAC-CPF](/eac) (describing creators) within the Encoded Archival Standards suite.

## Using the schema

Reference the schema at a stable URL. To always track the latest EAF v1 release:

```
https://standards.openpreservation.org/eaf/v1/eaf.xsd
```

To pin an exact version instead:

```
https://standards.openpreservation.org/eaf/v1.0.0/eaf.xsd
```

The XML namespace for EAF v1 is `https://standards.openpreservation.org/eaf/v1`. The namespace
stays constant across minor and patch releases; the precise version is carried in each schema's
`schema-version` attribute.

## Governance

EAF is maintained by the Technical Subcommittee on Encoded Archival Standards (TS-EAS) of the
Society of American Archivists. Development happens in the open on GitHub; this site hosts a
preserved, integrity-checked copy of each release.
